# 标普 500 新量化增强候选（2026-11-14）

本目录是一次独立的候选策略验证。数据使用缓存的 SPY 分红复权价格和 ^IRX 现金利率，区间为 2000-01-03 至 2026-10-16；信号在收盘判断、下一收盘成交，默认单边交易成本 10bp，另做 30bp 压力测试。

新候选有三条：

- **MTF-3**：30 周上升趋势和 10 个月均线同时成立时持仓 100%，只有一个成立时 50%，都不成立时 0%。
- **DD-RB**：从历史高点回撤超过 10%/20%/30% 时仓位降为 75%/50%/25%，回到相应区间再恢复。
- **TVT-50**：周线趋势成立时做 15% 目标波动率，趋势破位时仍允许目标波动率但上限降为 50%。

`summary_q3_q5.csv`、`segments.csv`、`yearly_returns.csv`、`drawdown_events.csv` 和 `sensitivity.csv` 支持 Q3/Q5 与参数敏感性检查。`dca_full.csv`、`dca_windows.csv` 和 `dca_summary.csv` 是每月投入 1 单位的 XIRR、浮亏和收益回撤比窗口结果。`fixed_weight.csv` 是与 MTF-3、TVT-50 平均仓位相同的固定持仓对照，用来区分择时贡献和单纯少持仓。

`verdicts.csv` 的预注册判定要求：主区间 Sharpe 或收益回撤比高于 B0；两个子区间各有一个风险调整指标高于 B0 且年化收益不低于 B0 三个百分点以上；30bp 成本下仍有一个风险调整指标高于 B0；10 年定投窗口中收益回撤比高于普通定投的比例至少 60%。`selfcheck.json` 检查权重范围、默认结果可重复和截断历史后的信号一致性。

复现：

```bash
uv run python -I scripts/research_sp500_new_enhance_2026_11_14.py
```
