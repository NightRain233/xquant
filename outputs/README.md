# 研究输出保留规则

`outputs/` 保存支持研究结论的可审计快照，不是所有临时计算的永久仓库。每个实验使用独立的 `outputs/<experiment>/` 目录，并与 Notebook、复盘文档使用相同 slug。

## 应提交的结果

- `research_summary.csv`、决策评分表和 Q3/Q5 核心指标。
- 年度、月度和回撤摘要。
- 最新信号、目标权重及纸面跟踪规则。
- 能直接支持结论的少量净值、回撤或敏感性图。
- Dashboard 数据构建脚本明确读取的源文件。

这些文件应能回答“比较了什么、结果如何、为什么得到当前结论”。

## 不应提交的结果

- 可重新下载的原始行情缓存。
- 调试导出、重复表格和没有进入复盘的批量图。
- 参数搜索的全部中间过程。
- `tmp/`、`cache/` 及编辑器临时文件。

临时结果放入实验目录下的 `tmp/` 或 `cache/`；这两个目录已被 Git 忽略。

## 更新要求

重新运行实验时，不要只覆盖文件。先确认数据窗口、参数和指标口径是否改变，并在对应 `docs/notes/` 复盘中更新快照日期、主要结论和限制。Dashboard 所需数据通过 `make dashboard-refresh` 从已审核输出重新生成。
