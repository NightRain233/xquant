# 术语表

研究报告里会用到下面这些词。每个词都先给日常说法，再说明它在本项目里的具体算法。不构成投资建议。

## 账户体验

| 词 | 日常说法 | 项目里的含义 |
|---|---|---|
| 最大回撤 | 账户最惨的时候，比历史最高点少了多少 | 净值从历史最高点下跌的最大幅度。持有标普 2009 年低点是 -55%。 |
| 修复时间 | 从最低点回到原来的高点，要再等多久 | 从回撤最低点到重新回到前高的时间。 |
| 水下时间 | 从高点跌下去，到回本为止，整段要等多久 | 从前高到重新回到前高的整段时间。 |
| 深水区天数 | 账户低于最高点超过 20% 的日子占多少 | 净值比历史最高点低 20% 以上的交易日占全部交易日的比例。 |
| 亏钱概率（持有 N 年） | 随便哪天买入，持有 N 年，最后亏钱的比例 | 所有起点的 N 年窗口中，期末低于期初的比例。窗口彼此重叠，不是独立样本。 |
| 年化收益 | 平均每年赚多少，按复利算 | 把整个区间的总收益折算成每年的复利收益率。 |

## 风险调整后的指标

| 词 | 日常说法 | 项目里的含义 |
|---|---|---|
| 夏普比率 | 承担同样的上下起伏，换回多少收益（越高越好） | 超出无风险利率的日收益均值 ÷ 日收益标准差，再乘以 √252。 |
| 收益回撤比 | 每承受一份最深的跌幅，换回多少年化收益（越高越好） | 年化收益 ÷ 最大回撤的绝对值。研究里也叫 Calmar。 |
| 年化波动 | 价格平时上下晃动的典型幅度 | 日收益标准差 × √252。 |

## 定投

| 词 | 日常说法 | 项目里的含义 |
|---|---|---|
| 定投 | 每月固定投入一笔钱 | 每月第一个交易日投入相同金额，本研究中每笔钱按所在策略的仓位规则管理。 |
| 一次性持有 | 一次投入，之后不再追加 | 2000 年初一次性投入，之后不增减，即持有标普（B0）。 |
| 时间加权收益 | 只看投资品本身涨跌，不受投入时点影响 | 净值曲线的收益，与何时投入的钱无关。定投的时间加权收益与一次性持有相同。 |
| 金钱加权收益（XIRR） | 考虑每笔钱何时投入后，实际拿到的年化收益 | 把每次投入和期末资产放在一起，求能使现金流净现值为零的年化利率。 |
| 定投最大浮亏 | 定投过程中，账户市值比已投入本金最少时低了多少 | 账户市值 ÷ 累计投入本金 − 1 的最小值。它小于价格回撤，因为后期买入的钱拉低了平均成本。 |

## 检验方法

| 词 | 日常说法 | 项目里的含义 |
|---|---|---|
| 基准（对照） | 拿来比较的做法 | 本项目通常以"一直持有标普（SPY）"为基准。 |
| 换起点 | 不同年份开始投资，结果是否一样 | 每年第一个交易日为起点，逐一重算。窗口重叠，结果不能当成独立证据。 |
| 循环位移检验 | 把买卖时点整体挪动，看随机挪动能不能得到同样的结果 | 把仓位序列循环移动，计算其中有多少比例的结果不低于真实结果。比例越小，说明时点越有价值。 |
| 参数敏感性 | 参数稍微换一下，结果还成立吗 | 在默认参数周围取一组网格，看通过的比例。只有一个点通过，就叫"魔法参数"，说明结果脆弱。 |
| 样本外 | 用没看过的数据检验 | 规则在数据形成之后才定下来，并用新数据验证。本项目的大部分结论仍是样本内。 |
| 事先写定 | 规则和标准在运行前就定好 | 研究在运行前记录规则、窗口和通过标准，之后不因结果调参。 |
| 多重检验 | 测的规则越多，偶然通过的越多 | 测试 10 条规则，就算都没有效果，也可能有一条偶然通过。 |

## 境内 ETF

| 词 | 日常说法 | 项目里的含义 |
|---|---|---|
| 溢价 | 场内价格比基金实际净值高出多少 | 场内收盘价 ÷ 单位净值 − 1。溢价高时买入，之后常会回落。 |
| 净值 | 基金每份的实际价值 | 基金公司公布的单位净值，通常滞后一天。 |
| 复权 | 把分红和拆分的影响折算回去，让历史价格可比 | 本项目区分"前复权"（旧的加法口径，已被更正）和"比例复权（全收益）"。 |
| QDII | 投资境外市场的基金，额度有限 | 513500、513100 等境内 ETF 持有的是海外资产，溢价受额度影响。 |

## 其它

| 词 | 日常说法 | 项目里的含义 |
|---|---|---|
| 仓位 | 账户里股票所占的比例 | 投资品市值 ÷ 账户总市值。半仓即 50%。 |
| 调仓 | 把仓位改回目标比例 | 规则触发后买卖。每年调仓次数越多，越需要持续操作。 |
| 成本（基点） | 每次买卖额外付出的费用 | 1 个基点 = 0.01%。研究里常用单边 10 个基点。 |
| 前视偏差 | 用了当时还不知道的信息 | 规则在某天只能用当天收盘前已知的数据。这是研究里最需要避免的错误。 |
