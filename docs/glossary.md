# 大白话术语表

阅读本仓库的攻略和复盘报告时，如果遇到陌生的词，随时来这一页查。每个词都先讲**普通人一眼能懂的日常意思**，再交代它在本项目里的具体做法。全部为知识说明，不构成投资建议。

---

## 一、三套方案里的核心名词

| 词 | 大白话怎么理解 | 在本仓库的方案里怎么用 |
|---|---|---|
| **逆波动配比** | 谁最近走得稳就多买谁，谁上蹿下跳得厉害就少买谁 | **方案 A（逆波动三组合）**核心规则：回看沪深 300、纳指 100、黄金近 20 个交易日的波动，每两周按波动倒数自动调一次比例。 |
| **季度再平衡** | 每三个月末把涨多跌少偏掉的仓位，拉回原定比例 | **方案 B（75% 标普 + 25% 黄金）**的做法：每年 3、6、9、12 月底调回 75:25，一年只动 4 次手，顺带实现“高抛低吸”。 |
| **30 周均线 / 半仓趋势（S2）** | 用过去 30 周的平均价当大趋势红绿灯；站在上升的均线上满仓，跌破就卖一半保命 | **方案 C（美股版）**核心规则：每周五收盘看一次，跌破就变成 50% 标普 + 50% 现金（或避险资产），把最惨腰斩压到三成左右。 |
| **趋势 + 控波动（TVT-50）** | 市场越剧烈震荡、仓位自动越轻；跌破大趋势时仓位封顶一半 | **方案 C（国内 `513500` 主力版）**：平时按 `15% ÷ 近 21 天年化波动` 算仓位，跌破 30 周均线后仓位封顶 50%，多余资金放货基或黄金。 |
| **日频防抖三档（MTF-3 ±2%～3%）** | 给两条大趋势线套上“±2%～3% 缓冲区”，真跌透或真涨稳才动手，不用傻等月底，天然实现右侧分批上车 | **方案 C（美股原盘进阶版）**：看 150 日（带上升要求）和 210 日均线，亮两灯买 100%、一灯买 50%、全灭留 0% 现金/避险盾；一年仅动 2～3 次，只适用于美股 SPY/QQQ。 |
| **防抖缓冲带（空间过滤）** | 围绕均线画上下各 2%～3% 的保护区，价格在中间来回磨蹭时按兵不动 | 像空调温控器避免压缩机反复启停：相比每天硬碰均线能砍掉八成假信号，相比死等月底又能及时躲开月内急跌。 |
| **日线趋势开关（SuperTrend）** | 给高波动资产装的一根大趋势安全带，走强持有、转弱立刻空仓 | **方案 A 的 7.5% 比特币卫星**：按日线 `SuperTrend(10, 3)` 亮绿灯拿满 7.5%、亮红灯立刻切回现金，不硬扛币圈深熊。 |
| **避险盾 / 黄金条件盾** | 股市破位减仓后，腾出来的钱不躺现金、改换黄金/美债；“条件盾”再加一句“只有黄金自己也在涨才换，黄金也在跌就留现金” | 低费率美股券商进阶选项（`S2_GOLD` / `S2_BOND_GOLD` / `S2_GOLD_TREND`），用来兼顾防深熊与躲黄金熊市。 |
| **右侧信号** | 不去猜“今天是不是最低点”，等大跌真的停住、价格重新站稳大趋势线后再加仓 | 区别于暴跌里的 1～2 天假反弹；宁可比最低点买贵一点，换取不再反复接飞刀的安心。 |
| **仓位 / 调仓** | 账户里投资品占总资金的比例；按规则把仓位改回目标比例就是调仓 | 半仓即 50%。年换手越高、调仓越频繁，手续费和心理折腾就越多。 |

## 二、看懂账户亏赚和煎熬程度的词

| 词 | 大白话怎么理解 | 在本仓库里的具体算法 |
|---|---|---|
| **最大回撤** | 账户最惨的时候，比历史最高点少了多少 | 净值从前高跌到低谷的最大跌幅。比如死拿标普 500 在 2009 年最惨跌了 -55%（10 万剩 4.5 万）。 |
| **水下时间 / 修复时间** | **水下时间**：从最高点跌下去到重新回本，一共熬了多久；**修复时间**：从最低点爬回原高点花了多久 | 死拿标普 2000 年高点后水下熬了 6.6 年；真正让人崩溃的往往不是跌幅，而是漫长回本等待。 |
| **深水区天数** | 账户一直比历史最高点低 20% 以上的“煎熬日子”占全部时间多少 | 死拿标普有 21% 的日子处在深水区；方案 C 半仓趋势把它压缩到了 7%。 |
| **亏钱概率（持有 N 年）** | 随便哪天买进去，拿满 N 年后还是亏钱的比例 | 统计历史上所有起点 N 年窗口的亏损占比（窗口有重叠，不能当独立概率）。 |
| **年化收益 / 年化波动** | **年化收益**：平均每年按复利赚多少；**年化波动**：价格平时上下晃动的典型幅度 | 波动越大说明坐过山车越刺激；逆波动和控波动规则就是靠这个数来自动减仓的。 |
| **夏普比率 / 收益回撤比** | 两个“性价比”分数——**同样受罪的程度下，谁赚得多**（越高越好） | 夏普 = 超出无风险利率的年化收益 ÷ 年化波动；收益回撤比（Calmar）= 年化收益 ÷ 最大回撤绝对值。 |
| **一次性投入 vs 定投** | 一次把一笔钱买进去不动 vs 每个月固定发工资就投一笔 | 两者投入的总本金不同，**不能只看最后账户总余额就说定投赚得比一次投入多**。 |
| **时间加权收益 vs 金钱加权收益（XIRR）** | **时间加权**：剔除存钱取钱，只看策略本身涨了多少；**XIRR**：把每笔定投日期算进去，你口袋里真实的年化回报 | 比较两个策略本身谁稳看时间加权（净值）；评估定投自己实际赚了多少看 XIRR。 |
| **定投最大浮亏** | 定投过程中，账户总市值最惨时比你自己一共掏出的本金少多少 | `(账户市值 ÷ 累计本金) - 1` 的最低值。通常比价格最大回撤温和，因为低位持续买入拉低了平均成本。 |

## 三、国内与币圈实盘避坑词

| 词 | 大白话怎么理解 | 为什么你必须知道 |
|---|---|---|
| **净值 / 溢价（高溢价）** | **净值**是基金每份真正值多少钱；**溢价**是你在股市里买的价格比真实价值贵了多少 | 国内 `513500` / `513100` 常因额度紧缺炒贵 5%～20%。历史证明贵 10% 以上硬买，后三个月平均白亏 10%～14%。 |
| **QDII** | 国内专门拿外汇额度去买海外资产的公募基金 | `513500`（标普）、`513100`（纳指）都是 QDII，额度用完就容易出现高溢价。 |
| **复权 / 比例复权（全收益）** | 把历史分红和拆分折算回股价里，让十几年的价格可以公平对比 | 旧“加法前复权”会高估含分红 ETF（如 `510300`）的历史涨幅；本仓库已统一修订为比例复权与真实分红记账。 |
| **交易成本（基点 / bp）** | 每次买卖付出的佣金和买卖价差（滑点）；**10bp = 千分之一（0.1%）** | 低佣金券商常用单边 10bp；币圈美股压测常用 30bp～50bp（千分之三到千分之五），高换手策略在高滑点下会严重失血。 |
| **资金费率（永续合约）** | 在币圈拿永续合约多单每天要交的“持仓利息” | 年化常达 5%～8% 以上。按 5% 滚 20 年会吃掉标普 500 **三分之二**的最终财富，长线绝不能用永续合约。 |
| **股息磨损** | 买不派分红的代理代币/产品，每年白白丢掉的分红收益 | 标普 500 历史年均股息约 1.80%；如果现货代币不派分红，20 年复利终值会白白蒸发 **三分之一**。 |

## 四、研究报告里常见的防忽悠检验词

| 词 | 大白话怎么理解 | 仓库里怎么拿它防自欺欺人 |
|---|---|---|
| **基准（对照）** | 拿来当参照物的最笨办法（比如一直死拿标普 500） | 新方法如果折腾半天还跑不赢基准，直接淘汰。 |
| **前视偏差（未来函数）** | 回测时不小心偷看了“当时还不可能知道的未来信息” | 本仓库严格要求“收盘看信号、次日再成交”，并严格对齐中美时差与基金净值公布延迟。 |
| **事先写定** | 跑回测之前就把规则和及格线写死，绝不看结果反过来改参数 | 避免“先射箭再画靶子”，保证结论经得起复查。 |
| **参数敏感性 / 魔法参数** | 把参数稍微调大调小（比如 30 周改 20/40 周），看效果还在不在 | 如果只有某一个精确数字有效、改一点就崩，就是脆弱的“魔法参数”，绝不采用。 |
| **换起点 / 循环位移检验** | 换不同年份入场重算一遍，或把买卖时点随机挪动看是不是纯靠运气 | 检验好成绩是真机制，还是刚好踩中某一年狗屎运。 |
| **样本外 / 多重检验** | 用**没参与过设计的新数据**验证叫样本外；一次测几十条规则总有一两条碰巧好看叫多重检验 | 本仓库大部分历史回测仍属样本内，所以强调**冻结方案、不再狂试新规则**，改用纸面账户前瞻跟踪。 |
| **恐慌指数倒挂（VIX/VIX3M > 1）** | 市场觉得眼下比三个月后更吓人，说明正在恐慌踩踏 | 已实测淘汰：只在 2020 闪电暴跌好用，平时假警报太多、年换手 3～6 倍，长期输给简单方案。 |
