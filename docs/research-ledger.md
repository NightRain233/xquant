## 状态说明

| 状态 | 含义 |
|---|---|
| 主线 | 当前的核心策略，见 [README](../README.md)。 |
| 通过 | 按研究前写定的标准，结果达标。仍是历史回测，不代表未来。 |
| 有条件 | 达标，但依赖少数事件或某段时期，需要进一步验证。 |
| 未通过 | 没有达到标准，或不如简单的持有。 |
| 参考 | 说明了某个现象或风险，但没有给出可直接采用的规则。 |
| 方案未执行 | 只有研究方案，没有跑数据。 |
| 已更正 | 原结论有口径或计算错误，以更正后的笔记为准。 |
| 归档 | 历史研究，不再作为当前建议。 |
